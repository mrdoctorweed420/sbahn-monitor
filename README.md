# sbahn-monitor

Private Auswertung von Fahrzeugumläufen der S-Bahn Stuttgart.

Sammelt, welche Einheiten auf welchen Fahrten eingesetzt werden, um
nachzuvollziehen, welche Fahrzeuge nachts in welchen Abstellanlagen stehen.

`.github/workflows/test.yml` ist ein manuell auslösbarer Erreichbarkeitstest.
